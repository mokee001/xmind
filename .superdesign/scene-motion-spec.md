# Echooo · 首页场景提案：动作与结构规范

> 状态：这是本轮探索的目标规范。2026-09-15 实际交付范围、未接入项与验证记录以 `demos/home-scenes/README.md` 为准。当前固定示例日期，光线为手动/播放模拟，未实现真实时钟或跨月加载。

本轮用户明确要求突破现有结构。此文件覆盖 `design-system.md` 中「结构锁定七列月历」的旧探索限制，仅适用于本轮首页提案。数据语义保留，布局可以重构；不修改 Demo、App、偏好或设置页。

依据：现有产品数据语义与用户明确提出的天空／泳池方向；Refero bundled `references/motion.md` 的反馈、连续性、层次原则及 reduced-motion 规则。未使用 live Refero 搜索。本轮环境动画是用户授权的时间表达，避免把普通控件也变成持续表演。

## 共同底线

- 顶部左侧始终看得到连接状态；右侧「偏好」和设置齿轮同级、44 px 以上可点范围。滚动后仍存在，不收入菜单。
- 没有 Tab、底部导航、未来照片、即将上屏内容、负面反馈入口。
- 已展示记录沿用 2026 年 9 月 2、5、8、11、13 日的五组示例内容；今日为 9 月 15 日。清晰标记「示例记录」，不能把场景模拟当作天气或设备回执。
- 日期始终可读、可定位；照片只出现在确有记录的过去日期。空白日有空白的视觉表达，不补图凑场景。
- 天空和泳池必须第一屏即呈现不同的空间结构，不允许顶部大插画下面接相同七列日历。
- 「今天」回到实际日期；日期详情可关闭并回到原位置。偏好／设置入口保留，预览若无实现则有明确轻提示，不应成为无反馈死按钮。

## A · 把日子交给天空

### 空间与信息组织

整屏是天空，不是被装进卡片的天空图。约 75% 天空、下方极低地平线，超大的日期随所浏览的日子变化。顶部功能悬浮在可靠的对比度薄层上。标题小，日期成为视觉主角。

以纵向的「日子」替代月历：右侧一条细时间刻度，主区逐日排列疏朗的日期节点，每日约 240–300 px。月份只在跨月位置出现一次。存在记录的日子在节点旁展开一张轻薄、略有透视的回忆小片；没有记录的日子只留日期与空气。照片与标注始终处于可读平面，不随云层扭曲。

首屏以今天为视觉锚点，下面显示近几日的回忆痕迹；向下回看更早的日子。右下角一个轻量「今天」按钮。月份定位可通过点击当前月份打开简洁列表，不把七列日历恢复到主页面。

### 时间如何被感知

1. 静止在今天：天空初始色相按本地时钟划分晨／昼／暮／夜，只有云影非常缓慢移动。它表达一天的节律，不显示城市、气温或天气预报。
2. 拖动／滚动：相邻日期之间的过渡距离映射到一个完整的日光周期。地平线泛亮 → 白昼 → 落日 → 星空；跨过日界时巨大日期更新。回看时动画方向反转。用户手势一停，场景停在相应过渡点；不能放开手后自动连续翻日。
3. 已展示回忆进入视口中段时，仅该小片 200 ms 淡入，日期与内容同时明确。点击打开日期详情，退出后保持所处日期和天空状态。
4. 演示者希望快速比较晨暮：放在提案外部的演示工具条提供「晨 / 昼 / 暮 / 夜」，不把调色控制或「播放天空」按钮当作正式首页导航。

### 可实现的最小架构

- `.scene` 为 `position: fixed; inset: 0; pointer-events: none`，用 4 个预渲染天空层做 opacity 交叉混合；无视频依赖。太阳／月亮独立 `transform` 层，云层最多 2 层。
- `.day-flow` 是真正的 DOM 滚动内容，日期节点有 ISO 日期数据；不要用 Canvas 绘制文字或可点击照片。
- 监听 passive scroll，单个 `requestAnimationFrame` 读取滚动位置并计算 `activeDayIndex` 与相邻节点进度。只写 CSS custom properties / opacity / transform；日期只在索引改变时更新 DOM。
- 初始本地时钟每分钟更新一次即可；历史浏览时暂停时钟驱动，返回今天再恢复。历史场景不是对应日期的真实气象记录。
- 日光过渡由滚动距离决定，不能依赖长时间 setInterval 自动翻页。交互可随时打断；日期跳转的平滑滚动最多 320 ms。

### Reduced motion

云／太阳位移全部暂停，取消视差与整天颜色连续扫过。跨入另一日期时直接更换背景关键帧，或仅做 100 ms opacity 淡变。日期列表、照片、详情仍正常使用，今天跳转为即时定位。不要把 reduced motion 实现为用户不能浏览日期。

## B · 日子浮在水面上

### 空间与信息组织

整屏俯视一个纵向延伸的泳池；水纹、池底分格、边缘石材成为真正的空间，不是图片背景。左侧窄池沿是连续日期尺，每个日期与右侧同高度水面对应，日期不漂动。右侧大面积水面承载已经展示的回忆。越往下是越久以前的日子，跨月用池底一条细分界线和月份标字。

没有七列格。日期占左侧约 52–62 px，右侧照片按日期位置交错分布，始终按时间排序。每张只轻微旋转，周围留大片水面。空白日只有池沿刻度和水，表达生活继续发生，不能每一天都塞一张素材。

顶部连接／偏好／设置固定在浅色池沿带，字与图标不压在高亮水纹上。标题「回忆日历」如池边简洁的铭牌，不采用天空方案的大日期排版。今天是一枚固定于日期尺的小圆浮标，水面保留为空；「今天」轻按钮仍可快速定位。

### 水与时间如何互动

1. 静止：一层缓慢的水光投影营造水面；照片本体保持稳定，不让阅读目标永远晃动。最多让图片外层影子做很小变化。
2. 纵向滑动：刻度经过视口中间的选中线时切换所浏览日期。水光相位随滚动变化，水面的回忆像从过去被带回身边，照片移动完全跟随 DOM 滚动，不用强制吸附阻断快速浏览。
3. 点击照片：触点向外扩散一次 360–450 ms 圆形涟漪，照片同时进入日期详情；涟漪不延迟点击结果。详情关闭回到原位置，不重新洗牌。
4. 从今天往未来方向拖到边界：保持今天空水面与一句「新的回忆，会在展示后留下」，不提前浮出未来照片。滚动反弹交给浏览器，不伪造未来记录。
5. 空白日期可点，只显示该日暂无已展示记录，不触发补图或自动生成。

### 可实现的最小架构

- 背景由一张经过选择的泳池素材或 CSS 池底 + 1–2 张透明水光纹理组成；水纹层 `pointer-events: none`，只变换 transform/opacity。避免实时模糊整个界面、重型 SVG 滤镜、逐像素水体模拟。
- `.pool-timeline` 是正常垂直文档流；每个 `.pool-day` 保留可访问的日期标题，`.memory` 使用普通 button。布局用单列时间轴 + 日期尺，记忆图片交错偏移控制在内容区内。
- 背景 texture 通过 CSS `@keyframes` 做 20–35 s 极轻的投影位移，离开页面或 `document.hidden` 时暂停。
- 用 CSS 伪元素实现一次性 ripple：触发时存点击相对坐标，设置 `--x/--y`，仅 scale+opacity，结束移除 class。详情仍按 240 ms 正常打开。
- `IntersectionObserver` 判定日期经过选中线；只更新日期铭牌与刻度选中态。记录卡的排列由日期固定决定，不能随机位置或重渲染跳动。

### Reduced motion

水光静止，关闭水面位移、涟漪与任何漂浮；照片按压只改变边框或阴影。日期与详情动作即时或 100 ms 淡变。仍保留水面材质、池沿日期尺和开阔间距，不能退化成另一个普通列表皮肤。

## 用于生成后的最低验收

1. 并排看第一屏：A 是天地纵深和大日期，B 是俯视水体和池沿日期尺；两者都没有七列日历。
2. 录制一次 6–10 秒操作即可看到 A 日光／日期联动，B 水面／日期尺／一次涟漪的差异；不是静态图片加文案。
3. 390×844 的连接、偏好、设置均可见，触区充足；背景最亮／最暗状态下字仍可读。
4. 五组相同示例历史日期可打开详情；今天与未来无照片；无真实天气或上屏成功的虚假声称。
5. 快速滚动、点击今天、详情关闭后位置不丢；无持续生成 DOM、无每帧 layout 测量循环。
6. reduced motion 与后台页暂停可用。不得让环境动画影响主要操作响应。
