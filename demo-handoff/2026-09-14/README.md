## 换电脑启动

需要 Python 3.9 或更新版本，无第三方依赖，无需 npm。

```sh
git clone --branch codex/demo-handoff-20260914 --single-branch https://github.com/mokee001/xmind.git xmind-demos
cd xmind-demos/demo-handoff/2026-09-14
python3 start-all.py
```

Windows 可使用 `py start-all.py`。会启动三个独立进程并打开浏览器；关闭终端或按 Ctrl+C 停止。

也可只运行某个版本：`python3 serve.py --demo 1`，将 1 改为 2 或 3。端口冲突时加 `--port 8891`。所有服务只监听本机。

## 方案与接手上下文

- **D01**：用户否定刊物封面、期数和额外“翻开”层。最新要求是首页无历史记录，并有从授权到连接、展示设置、生成与当前展示的完整流程。完整结果在模拟屏幕回执后短暂停留再出现在手机；不要求“我看到了”，也不保证用户先亲眼看实体屏。源码是 index.html、style.css、app.js。更早的 App 1.3.5（28）预览不是此次三个方案之一，仍保留在原 App 分支。
- **D02**：连接后直接进入安静日常首页；照片整理并行、墙面独立更新。没有结果领取、信封或要求用户去看屏幕的环节。历史画面在次级入口；包含慢速、照片不足、连接失败等演示分支。index.html 是可直接运行的版本，source-fragment.html 保留原会话原型源文件；以后修改 index.html 为准。
- **D03**：原四步 v2.2：授权、连接、展示设置、预览上墙。人物气泡与主题选择。来源分支 codex/onboarding-demo-v2.2，基准提交 2380b9236fec752e32eb5b1469675c6720a047c0。原工作区仅新增交接技能与记录，尚无产品设计修改。历史交接参考位于 handoff-reference，旧本机路径和未推送状态不适用于此包。

## 素材和能力边界

公开仓库不包含私人照片、人物识别索引、相册缓存、密钥、安装包、node_modules。D01 / D03 原私人历史样张改为随包提供的 SVG 示意素材；D02 原本就是 CSS 示意画面。封装后无需旧电脑目录。选择人物和主题用于界面演示，不代表真实筛选；三套均不连接真实设备，不读取或上传手机相册，状态仅在当前页面会话生效。
