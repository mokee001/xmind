# 首页场景探索

这是两款独立的动态首页概念及其对比画布，仅用于判断视觉方向。现有回忆日历 Demo、偏好、设置、引导流程与正式 App 保持原有实现。

## 文件

- `index.html`：对比入口。桌面并排显示两款 390 × 844 的首页画面，按可用窗口等比缩放；手机通过顶部按钮切换提案。
- `sky.html`：流动天空概念。
- `pool.html`：漂浮泳池概念。

首页概念通过独立 iframe 嵌入，画布中的“独立查看”直接打开对应文件。地址加 `#sky` 或 `#pool` 可指定手机初始显示的提案。原版入口指向本机 8095 端口的回忆日历。

## 本地运行

使用任意静态 HTTP 服务托管此目录，然后访问 `index.html`。无需安装依赖或执行构建。已启动本地预览：`http://127.0.0.1:8096/`，静态服务监听 127.0.0.1。

## 范围

这是首页视觉与动态表达探索，展示内容均为示例。不接入设备、不上传照片，也不代表真实上屏回执。后续只有在用户选定方向后才将对应方案接入完整 Demo。
