## 结构差异

| | 生活画布（v2） | 极简叠片卡组 |
| --- | --- | --- |
| 首页主要单位 | 连续的生活画布 | 两列排列的回忆组 |
| 图片如何出现 | 自由排布，照片与生活细节自然相连 | 封面与后方叠片暗示组内内容 |
| 回看方式 | 直接在画布内浏览与回看 | 先选一组，再展开回看 |
| 信息主次 | 照片与生活细节优先，日期辅助 | 卡组与封面优先，日期辅助 |

两案只提供历史回看，左上角持续显示连接状态，右上角为偏好与独立设置。没有底部 App Tab，没有要求用户编辑拼贴的操作。

## 比较页行为

- 桌面宽度至少 900px：并排展示两案，内部视口为 393×852，无模拟手机外框。
- 较窄视口：只展示当前方案。外层“生活画布 / 极简叠片”是设计评审切换，不属于 App 导航。
- `#collage` / `#quiet` 可直接定位方案；键盘左右方向键也可切换外层方案。
- Iframe 按统一比例缩放，保持内部 393×852 的布局。单独打开链接用于真实设备宽度体验。
- 页面保留 `../studies/` 历史提案入口。
