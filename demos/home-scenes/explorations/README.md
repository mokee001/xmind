# 首页概念探索 · 第四轮

用户已认可上一轮用不同结构和手势表达概念，要求再给三套从意象、界面到交互的完整方案。当前是三个完整交互提案，不选择胜出方案、不迁移 App 或发布 TestFlight。

## 共同产品边界

- 首页回看已经展示的历史，不预告未来内容。今天为 2026-09-15，示例历史为 2、5、8、11、13 日。
- 顶部固定左侧连接状态，右侧偏好和独立设置。没有底部 Tab。状态明确为示例，偏好和设置为入口说明。
- 后台选片、人物偏好和设备逻辑沿用现有产品，不引入收藏、负向筛选、补齐日历、养成或任务。
- 三套复用上一轮生成的三联摄影素材，通过 CSS 裁切；没有使用用户照片；复用已上传的示例照片，不新增照片上传。

## 设计参考与决定

本轮无 live Refero 工具，采用官方一手参考与 Refero bundled motion / visual-workflow。三个方向各自保留主要特征，不混成同一种布局。

| 方向 | 主参考与保留特征 | 界面决定 | 交互决定 |
| --- | --- | --- | --- |
| 回忆星图 | [NASA Eyes](https://science.nasa.gov/eyes/)：空间探索与目标聚焦 | 午夜蓝、固定月份星点、细线只表达日期先后，照片在星点上展开 | 平移、缩放、点选聚焦；始终有复位与返回入口 |
| 时光唱片 | [TP–7](https://teenage.engineering/products/tp-7)：把时间变成可以拨动的实体卷盘 | 浅银面板、黑色圆盘，橙红只标当前日期；照片保持正向 | 转动外圈、松手吸附；按钮与刻度均可代替旋转，不暗示音频播放 |
| 时间地层 | [USGS Layers](https://www.usgs.gov/educational-resources/find-feature-layers)：上新下旧、时间累积成层 | 连续宽幅地层、波状边界、层内照片；不切成独立卡片 | 点按拉开一层，其余层压缩保留时间上下文；再次点按收起，滚动不抢手势 |

## 方向锁

星图必须是空间画布，拒绝规则日历格、飘动气泡或点开后统一列表。转盘必须以圆周定位为主，拒绝横向胶片、自动旋转和播放/暂停按钮。地层必须以连续截面组织时间，拒绝六个悬浮卡片、虚假岩石渲染和要求用户擦除内容才能查看。

媒体只用于已发生的日期。代码绘制的星轨、刻度和地层边界属于可编辑信息结构，不冒充摄影素材。减少动态效果时取消镜头移动、旋转惯性及层叠弹动，直接显示最终状态。

## 对用户的意义与代价

- 星图：空间探索带来偶遇感；日期查找可能较慢，需要稳定位置和复位。
- 唱片：单手拨动直观有触感；精确定位依靠刻度与按钮补充。
- 地层：同时保留历史厚度与当前细节，适合长久积累；长期扩展需增加月份折叠，不能无限堆叠。

入口 `http://127.0.0.1:8096/explorations/`。上一轮保留在 `/interactions/`。
