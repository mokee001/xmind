# 三种首页交互 · v1

本轮响应用户对三款静态概念结构相似的反馈，制作独立可操作 Demo。旧概念图与已有 App 不变。

## 参考与决定

沿用 `.superdesign/concepts/2026-09-15/` 中已研究的光影纸面、织物、连续摄影三个视觉方向。用户本轮明确授权改变布局与交互。Refero bundled motion.md 提供可中断状态切换、保持上下文、减少动态效果与键盘备选原则。没有使用 live Refero。

| 方案 | 首屏/信息单位 | 主要动作 | 保留的视觉特征 |
| --- | --- | --- | --- |
| 纸面 | 一天、一张完整纸页 | 左右拖动翻日；月份目录直接跳转 | 白纸、折痕、投影、纸层厚度 |
| 织毯 | 一整月、30个连续织纹位置 | 点选日期展开；返回整月 | 连续纤维、色彩片段、经纬关系 |
| 长卷 | 一幅回忆和胶片轨道 | 连续拖动时间定位；松手吸附 | 全幅摄影、深色底、银灰刻度 |

共同固定：2026-09-15、状态与照片均为示例；5个历史日期为2、5、8、11、13；今天及未来不预告照片；顶部连接状态、偏好和设置独立入口。偏好/设置仅展示入口说明，尚未迁移完整流程。没有修改选片/聚合引擎或模板规则，也不做真实设备上屏。

`assets/memory-scenes.png` 为本轮 ImageGen 生成的等宽三联摄影素材，左海边、中咖啡馆、右森林。源图未修改，通过 CSS 裁切展示。未使用用户私人照片。原始提示词保存在 `assets/prompt.txt`。

## 预览与核对（2026-09-15）

- 对比入口：http://127.0.0.1:8096/interactions/；独立入口为同目录 paper.html、weave.html、film.html。桌面并排，手机通过顶部方案选择切换；这是提案比较工具，不是 App 底部 Tab。
- 三款已分别导入原 Superdesign 项目，新草稿 v1；ID、公开链接和源文件 SHA-256 见 manifest.json。回取后 HTML 与提交文本逐字相同，无导入警告。
- 浏览器实际核对：393×852 独立页面，1440×1080 桌面对比，以及 393×852 手机比较切换。纸面 13 日单次左拖至 12 日、月目录跳至 11 日及照片展开；织毯 13 日展开、返回整月、15 日空状态；长卷轨道拖动、画面单段拖动、回到今天及设置弹层均通过。三款在线版本也已渲染核对。
- 修复纸面重复手势防护：起始日期快照、pointerId 与一次性提交；按钮打断旧手势并取消旧动画。纸面事件桩六项回归、三份最终脚本语法检查通过。
- 公开 Superdesign 页面注入的组件运行器出现一次 MutationObserver 初始化错误（原型源码及回取 HTML 均不含该代码）；现场核对三款主交互不受影响。本地比较页不加载该运行器。公开图片首次加载依赖网络。
- 本轮仅交互原型；状态、照片和历史均为示例，偏好与设置是入口说明。未改原 App 与精选基准，未发布 TestFlight。
