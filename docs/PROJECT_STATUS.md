## 两台电脑协作规则

1. 开始工作时先运行 `sync-project.command`。
2. 只在 `hardware/waveshare-eink-spectra6` 或明确命名的功能分支工作。
3. 结束工作前更新本文件，并只暂存本次相关文件。
4. 完成检查后提交并推送；没有推送的修改不会出现在另一台电脑。
5. 另一台电脑同步成功后再继续修改相同文件，避免同时产生冲突。
