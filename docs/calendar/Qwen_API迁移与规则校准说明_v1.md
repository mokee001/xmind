# AI 手帐日历 Qwen API 迁移与规则校准说明 v1

## 1. 迁移目标

本次迁移不是重新训练基础模型，而是把此前在 GPT Vision 会话中校准出的产品判断，固化成可版本管理、可测试、可回退的 Qwen 决策模块。

模型分工：

| 模块 | 实现 | 是否调用生成模型 |
|---|---|---|
| 素材导入、日期和质量过滤 | 现有本地流程 | 否 |
| 图片选择与基础视觉理解 | 现有及格流程 | 暂不替换 |
| 图片处理决策 | Qwen3.8-Max | 是 |
| 裁切、抠图、去背、缩放 | 本地执行器 | 否 |
| 空白格线描插画 | Qwen-Image-3.0-Pro | 仅必要时 |
| 坐标、碰撞、图层和渲染 | 现有本地规则 | 当前不替换 |
| QA 和失败回退 | 本地程序 | 否 |

## 2. “教会新 API”是怎么实现的

每次图片处理决策请求包含四部分：

1. `prompts/treatment_decision.md`：模型角色、判断顺序和禁止事项。
2. `rules/treatment_rules_v1.json`：处理方式、图片数量、旋转、文字证据、插画和装饰层等固定规则。
3. `training/illustration_text/calibration_cases_v1.jsonl`：30 个已人工校准的正例与反例。程序按当前输入自动选取最相关的少量案例，不把全部案例重复发送。
4. `ImageTreatmentDecision` Schema：模型必须填写的结构化字段。

模型输出后还要经过两层本地检查：

- Pydantic 检查字段、枚举、数值范围和必填项。
- `_validate_decision` 检查产品硬规则，例如每天最多 3 张、旋转不超过 10 度、插画文字长度、文字来源、连续空白条件和插画风格 ID。

Qwen 的 JSON 模式保证输出为合法 JSON，但 Schema 服从性由本地检查保证。第一次不合规时，程序把具体错误反馈给模型，要求重新输出完整 JSON；默认最多尝试两次。连续失败则停止，不生成错误日历。

## 3. 决策请求边界

Qwen3.8-Max 可以：

- 在已有 0-3 张候选素材中确认需要使用的素材。
- 在固定处理方式中选择最合适的一种。
- 判断主体、背景价值、裁切风险、抠图适配度和小格可读性。
- 为处理执行器给出主体框、锚点、旋转、文字和插画简述。

Qwen3.8-Max 不可以：

- 把照片移动到其他日期。
- 自由创造处理方式或修改固定尺寸。
- 直接输出最终坐标。
- 直接编辑原图或渲染整月日历。
- 编造用户没有提供的经历、情绪、关系、地点、金额或时间。

## 4. 插画生成边界

只有处理决策为 `illustration_only` 或 `illustration_with_text` 时，执行层才允许调用 Qwen-Image。

固定风格：

- 黑色单色手绘线描，轮廓优先、低细节。
- 一个核心主体，最多一个很小的辅助物。
- 特写或单一视觉重点，不画人物全身，不画完整环境场景。
- 禁止写实、3D、彩色填充、渐变、阴影、品牌标志、二维码和条形码。
- 图片中不生成正文；文字由本地程序按纯文字 10 号、插画加文字 8 号绘制。

生成图先保存为本地 PNG，再由本地执行层去白底、缩放、碰撞检查和渲染。模型不控制最终版式。

## 5. 配置和凭证

默认配置：

```json
{
  "decision_backend": "qwen",
  "decision_mode": "shadow",
  "api_enabled": false,
  "qwen_decision_model": "qwen3.8-max",
  "qwen_image_enabled": false,
  "qwen_image_model": "qwen-image-3.0-pro"
}
```

密钥优先从以下环境变量读取：

- `QWEN_DECISION_API_KEY`
- `QWEN_IMAGE_API_KEY`

Mac 本地使用 `配置Qwen密钥.command` 将密钥写入钥匙串。项目、日志、报告、Git 提交和测试夹具中不得出现真实密钥。

曾经出现在聊天或截图中的密钥视为已经泄露，必须先在平台废止并重新创建，不能继续使用。

## 6. 上线步骤

### 阶段 A：离线保持现状

- 两个 API 开关均为 `false`。
- 继续使用已有 `treatment_plan.json` 生成 2026 年 7 月日历。
- 确认新代码没有改变最终渲染结果。

### 阶段 B：决策影子模式

- 选择 10-20 个代表性日期，覆盖人物、宠物、风景、海报、多图、纯文字、插画加文字和连续空白。
- Qwen 生成新决策，但不覆盖旧计划。
- 比较处理方式、文字保真、插画触发和本地校验通过率。

建议门槛：

- 本地 Schema 与硬规则通过率 100%。
- 处理方式人工可接受率不低于当前 GPT Vision 基线。
- 必须排除素材漏放为 0。
- 无证据文字和事件编造为 0。

### 阶段 C：启用处理决策

- 将 `api_enabled` 改为 `true`。
- 低置信度、两次校验失败或服务异常时保留旧计划或进入人工复核。
- 不因 API 失败阻断已有离线渲染能力。

### 阶段 D：插画小流量启用

- 先确认账号拥有 Qwen-Image-3.0-Pro 权限。
- 对 20 个插画简述做风格抽检。
- 通过后将 `qwen_image_enabled` 改为 `true`。
- 生成失败时优先查素材库，其次回退纯文字或留白，不影响整月输出。

## 7. 版本与回退

每次生成建议记录：

- 决策后端与模型名。
- 规则版本和提示词版本。
- 校准案例版本。
- API 请求 ID、尝试次数和用量，不记录密钥和临时图片 URL。
- 原决策、新决策、本地校验和最终采用结果。

回退时只需关闭 `api_enabled` 和 `qwen_image_enabled`，现有确定性 7 月渲染器仍可继续读取准备好的计划文件。
