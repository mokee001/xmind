# AI 手帐日历图片处理决策规范 v1

## 1. 适用范围

本规范只解决“已经选中的日期素材应该如何处理”，不重新完成选图，也不决定素材在整月画布上的最终坐标。

当前由会话内 GPT Vision 按本规范进行判断；API 批处理暂时关闭。两种方式使用相同的输入、规则和输出结构。

当日期没有合格照片，或只有不适合原样展示的文字截图时，使用 `插画与文字专项校准规范_v1.md` 判断 `blank`、`illustration_only`、`text_only` 和 `illustration_with_text`。

处理决策模型负责：

- 在固定处理类型中选择最美观且可执行的一种。
- 指定主体、裁切重点、旋转角度、文字和辅助素材需求。
- 给出备选处理方式、置信度、命中规则和风险。

本地执行器负责：

- 根据处理类型读取固定尺寸和安全区域。
- 完成裁切、圆形或椭圆遮罩、抠图、文字排版和素材组合。
- 拒绝超过硬约束的参数并执行回退。

## 2. 全局硬规则

1. 原则上每个日期使用 1 张图片，最多不超过 3 张。
2. 没有合格照片时允许留白，也允许使用线描插画。
3. 可以为了突出主体和提升美观进行裁切。
4. 左右旋转绝对值不得超过 10 度。
5. 处理方案以整体审美效果为首要标准。
6. 异形抠图不得增加白色描边或阴影。
7. 所有素材仍属于原拍摄日期，处理方式不能改变日期归属。

## 3. 固定处理类型

| 类型 ID | 中文名称 | 固定规格 | 主要适用场景 |
|---|---|---|---|
| `proportional_full_image` | 比例内完整图片 | 54×63，日期格 padding 1 | 风景、完整构图、人物全身、演出照片 |
| `illustration_only` | 无图片插画 | 54×63，日期格 padding 1 | 至少两个连续空白日期中的装饰填充 |
| `illustration_with_text` | 无图片插画+文字 | 插画 54×50；文字 52×14 | 无照片但有有意义的文字内容 |
| `text_only` | 纯文字 | 52×62，padding 2 | 心情、聊天或纯文字内容 |
| `non_cell_ratio_image` | 非日历格子比例图 | 46×63；左 padding 9、右 1 | 电影、游戏海报和专辑封面 |
| `multi_irregular_cutout` | 多张异形抠图 | 安全区 72×80；极限区 78×86 | 最多 3 个不同主体组合 |
| `circle_image` | 圆形图片 | 63×63 | 穿搭局部、动物、圆形聚焦主体 |
| `oval_image_with_cutout` | 椭圆图片+抠图 | 椭圆 54×63；总范围遵循安全区 | 主活动图片+票据等辅助素材 |
| `irregular_cutout_with_text` | 异形抠图+文字 | 安全区 72×80；极限区 78×86 | 清晰且有意义的物品展示 |
| `irregular_cutout` | 异形抠图 | 安全区 72×80；极限区 78×86 | 人物半身、宠物、玩偶、食物组合 |
| `blank` | 留白 | 无素材 | 保留呼吸感更美观 |

## 4. 文字规范

- 字体：`momozhuanji`
- 纯文字字号：10，字重 600
- 插画加文字字号：8，字重 600
- 异形抠图加文字字号：6，字重 600
- 纯文字最多 24 个汉字。
- 插画加文字和异形抠图加文字最多 14 个汉字。
- 所有显示文字必须记录 `text_source` 和 `text_source_excerpt`。
- 有生活意义的网页内容使用 `ocr_web_content`，网页截图原图不进入日历格。
- 直接引语只能来自用户输入、人工标注或 OCR 原文。
- 模型总结不得伪装成用户原话，不得增加没有证据的情绪、事件或人物关系。
- 异形抠图加文字使用穿插排列，但不得遮挡主体关键部分。

插画使用 `journal_line_doodle_v1` 风格，并优先从设计师插画库选择。当前不允许模型自由生成或重绘插画。

## 5. 安全区域

异形抠图类使用两级范围：

- 安全区域：72×80。模型和执行器应优先把所有可见主体控制在该区域。
- 极限区域：78×86。为了审美可以局部进入，但任何可见内容都不得超过。

圆形图片可以突破所属日期格，但圆心必须保留在所属日期格内。最终布局阶段仍需检查相邻日期数字和主体保护区。

## 6. 决策优先顺序

1. 排除硬性不可用内容。
2. 判断背景是否属于照片意义的一部分。
3. 判断主体能否可靠裁切或抠图。
4. 判断单主体、多主体、图片加文字或图片加辅助物料。
5. 在满足硬约束的方案中选择审美效果最好的一种。
6. 同时给出保守的备选处理方式。

## 7. AI 输出与执行边界

AI 可以输出：

- 处理类型。
- 主体说明和主体框。
- 裁切重点。
- ±10 度范围内的建议旋转。
- 主素材和辅助素材关系。
- 是否需要短文字或插画。
- 文字来源、原始文字片段和是否为直接引语。
- 插画角色、插画素材库类别、风格 ID 和线描简述。
- 中性装饰是否由明确的版面平衡需求触发。
- 包含当前日期的连续空白日期数量。
- 备选处理方式、理由、风险和置信度。

AI 不可以输出：

- 超出规则表的任意尺寸。
- 超过 3 张的日期素材数量。
- 超过 ±10 度的旋转。
- 白色抠图描边或阴影。
- 最终整月画布坐标。
