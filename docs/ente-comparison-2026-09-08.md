## 接口封装和移植是什么意思

**接口封装**是保留 Ente 的实现和运行环境，给它增加统一的输入输出入口。当前链路为：实验台 → Python 运行器 → Ente Rust 识别与 Dart 回忆计算 → JSON 分组结果 → 实验台。它全部在本机执行，不要求上传到 Ente 或自建云服务器。当前入口只服务固定测试集，还不是通用产品 SDK。

**移植**是把所需能力适配到现有 Expo/React Native App。例如通过本地原生模块调用模型，将所需 Dart 成册逻辑改写为 App 能执行的实现，并接好照片资源 ID、索引缓存和增量分析。除结果一致性外，还需验证权限、后台中断、内存、发热等手机行为。

也可以在手机中通过桥接保留部分现有实现，但仍需整合运行时和依赖，不能直接安装一个 npm 包就获得完整 Ente 功能。两条路径都不会自动消除上游代码和模型许可义务。

本轮完成的是本机对照验证；手机移植、生产发布和商业分发许可评估未包含在本轮结果中。
