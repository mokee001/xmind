# 首次自动上屏 Demo v0.3.5

参考锁定：现有 demos/calendar-app 欢迎、连接页的纸白/鼠尾草绿、字号与按钮。只补首次上屏链路，不添加封面、揭晓或确认投送操作。抽象纸片呼吸动画不包含生成成片。支持减少动态效果。

连接和设置保存成功 → 有限批量本机选片 → 上传首批/生成 → 自动投送 → 对应设备显示回执 → 轻反馈 → 日历。全相册整理不得阻塞首屏。Demo 各阶段纯计时模拟，不验证真实硬件或算法耗时。

可在桌面侧栏选择：正常、照片不足、上传中断、回执超时。异常首次触发，重试模拟恢复；真实照片不足必须补充授权后重新评估，不能直接假成功。真实回执超时应先查询对应发布 revision，避免重复发布。
