# 首次上屏协调 Demo v0.3.7

日期：2026-10-11。范围仅 `demos/calendar-app/`；本页描述本地模拟机制，不代表 App 已提速、设备实测或 TestFlight 发布。

## 可体验入口

- 完整正常流程：`http://127.0.0.1:8095/?v=0.3.7#welcome`
- 准备尚未完成：`http://127.0.0.1:8095/?firstWall=preparation-slow#welcome`
- 可用照片不足：`http://127.0.0.1:8095/?firstWall=empty#welcome`
- 上传中断：`http://127.0.0.1:8095/?firstWall=upload#welcome`
- 回执超时：`http://127.0.0.1:8095/?firstWall=receipt#welcome`
- 连接恢复回归：`http://127.0.0.1:8095/?connection=cloud-offline#welcome`

桌面左侧可选场景，选择后点击「从新用户流程体验」。完整主线为欢迎与照片授权 → 连接照片墙 → 第一幅回忆 → 日历。新开页面尚未完成授权或连接时，直接访问 `#first-wall` 会返回欢迎页。重新体验保持此前保存的偏好、更新时间和设备名。

## 这次实际改变了什么

旧 `first-wall.js` 进入页面后依次等待四段固定计时；异常重试一律重头开始。此版通过 `createFirstWallJourney` 保存独立工作状态，并由完成事件推进，渲染页面只订阅状态：

1. 照片授权即触发隐藏的本地准备。准备与蓝牙权限、发现设备和 Wi-Fi 连接同时进行，未授权不开始。
2. 连接与设置保存成功后才启动模拟首批上传。若本地准备已结束则复用；若尚未完成就继续等待同一任务，不提前显示成功、不重新开始准备。
3. 首幅所需的上传与服务候选就绪后，立即开始生成，不等待完整首批。其余上传保持未启动，不与首次生成和投送同时运行。
4. 生成、投送、设备回执分别完成后才切换相应画面。只有最后的模拟回执就绪才出现完成文案，并启动其余模拟上传。点击进入日历后，这项后台工作继续；回执失败时不会提前放行。
5. 失败保留已完成步骤：上传重试保留本地准备；回执重试保留上传、候选、生成与投送，只重新等模拟回执。异常场景明确在首次重试时模拟恢复，不代表正式错误一定可由重试解决。
6. 首幅未完成时离开流程会暂停并取消待执行回调；回来复用已完成步骤。重新体验销毁旧流程；照片权限撤回或范围变化使旧准备失效，旧回调不能推进新授权范围。

协调器是本地事件模型。定时器仅作为模拟服务的驱动器，各阶段仍使用明确的示例时长；没有用「缩短四段 sleep」充当性能修复。`preparation-slow` 使用更慢的准备事件，连接期间若尚未完成，首幅页面会自然继续等待。若用户连接操作本身更慢、准备已经完成，也会正常复用，而不额外制造等待。

## 产品与真实性边界

- 手机只保留原等待画面、失败恢复、完成反馈及 Demo 标识。不新增照片数量、整理进度、候选版本、手动整理或技术面板。
- 桌面手机框外的「查看模拟事件」用于核对授权、准备、候选、生成等先后关系；明确标注“本地模拟 · 非实测速度”。
- 不读取手机相册、不上传照片、不运行精选模型，不更改冻结筛选规则、人物或主题偏好。
- 所有上屏反馈是本地模拟，不能当作真实设备回执；这次不新增真实日历记录，不用模拟照片冒充当天实际展示内容。
- 未发布真实 App。对应原生预热、缓存复用与服务候选检查正在独立候选分支 `codex/first-wall-prewarm-20261011` 验证，用户确认本 Demo 后再合并；实际速度仍须用同一手机与设备测量。

## 设计参考锁定

采用用户已确认的 `demos/calendar-app/` v0.3.6 页面作为唯一主视觉目标，沿用 Refero 的参考锁定与质量检查方法。没有重新设计手机界面或引入外部风格。

| 决策 | 依据 | 保留方式 |
| --- | --- | --- |
| 纸白底、鼠尾草绿、宋体标题 | 已确认 Demo 的 `style.css` 与 `onboarding.css` | 不改色彩、标题字体与按钮角色 |
| 两步设置、连接后首幅 | 用户已确认流程及本次提速要求 | 授权和连接仍在原页面，后台预热不增页面 |
| 手机只显示必要反馈 | AGENTS「选片后台化」 | 模拟内部事件仅在桌面手机框外呈现 |
| 状态反馈不闪烁 | 现有等待动画与可访问性规则 | 仅当标题/描述/状态变化时重绘，保留 reduced-motion |
| 恢复不重复已完成工作 | 本次真实链路故障与用户要求 | 回执重试不重新上传、生成或投送 |
