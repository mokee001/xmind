# 回忆筛选与聚合算法 V1.0.0

此版本固定的是可用于其他照片数据集的**代码、规则参数、模型约定和依赖**，不是固定的 8 个相册或照片 ID。

Git 标签：`recollections-rules-v1.0.0`。独立分支：`codex/recollections-rules-v1.0.0`。代码清单及指纹：`config/recollection_rules_v1.0.0.json`。

## 固定的行为

1. 从当前输入图库过滤非照片、不合格画质及该数据集的排除项。
2. 用 Ente MobileCLIP-S2 图片/文本向量与本地 Vision 分类构造主题候选；正面与排除提示词共同约束主题。
3. 从时间、GPS、主要拍摄区域、出行连续性构造旅程候选，再按时间、地点或多个原始锚点的视觉证据补充照片。
4. 同内容主题允许跨日期。只有至少两个年份各有充足候选时才分年；不强行补造日期、人物或宠物身份。
5. 先去强重复，再判断最低张数；每册最少 12 张、最多 24 张。质量、美感、回忆评分与画面/日期多样性共同决定选片，然后按时间排序。
6. 推荐评分考虑覆盖、丰富度、旅程、收藏与近期观看；最多 4 个优先推荐，同主题或高度重合相册不会同时优先推荐。
7. 页面统一展示全部未隐藏的合格相册，优先推荐排前；最终相册数量、标题中的地点/年份、成员和封面均随输入变化。

本版的宠物、餐桌、自然、舞台、艺术是预定义主题；不是任意主题的自动发现系统。阈值为现阶段确认的规则，不保证所有图库都产生相同数量或同等质量的回忆。

## 更换照片

为新图库创建独立数据集并完成对应的基础特征、Vision 与 Ente 识别，再调用 `selection_lab.recollection_feed.build_feed(lab)` 或将其设为活动数据集后运行 `python3 tools/run_recollection_feed.py`。

`lab` 必须指向新图库自己的缓存和状态；如果提供历史排除输入，也必须属于该图库。结果和偏好由数据集标识隔离，不应复制上一批照片的结果/偏好到新数据集。新图库不足 12 张同主题照片时，该主题不会生成相册。

模型权重不纳入 Git；模型文件名称及 SHA-256 记录在代码版本清单中。准备本地推理环境的脚本一并保存。真正换图处理仍需要这些模型、相应特征和新原图，不依赖先前保存的 8 个相册。

## 回退代码

推荐在独立工作树恢复，避免覆盖同时进行的 App、硬件及其他实验修改：

```sh
git worktree add ../photo-wall-recollections-v1 recollections-rules-v1.0.0
```

这会检出完整代码版本。数据和模型位于被 Git 忽略的本地目录，需要为该工作树配置或准备。正式合并时审核该版本提交的变更，并处理共享依赖的冲突；不要把旧照片结果当成算法版本。

此前 `outputs/recollection-versions/recollections-v1.0.0/` 中的存档只作为样本效果对照。算法回退以本 Git 标签为准。
