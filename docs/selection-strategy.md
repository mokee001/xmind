# 照片策展与主题选片策略

## 目标

照片理解只执行一次，选片策略可以先服务所有模板，之后再独立绑定旅行、宠物、家庭等主题。模板只负责视觉排版，不负责识别照片，也不硬编码选片权重。

## 处理顺序

1. `backend/tagger.py` 审核来源。有相机 Make/Model EXIF 的图片标记为 `camera`；
   无 EXIF 但通过内容检查的图片标记为 `shared`；明确截图、文档和拼图标记为
   `non_photo` 并排除。无 EXIF 本身不再作为拒绝依据。
2. `backend/clip.py` 为合格照片生成 CLIP 向量；服务离线时安全回退。
   对 `shared` 候选还会比较真实摄影与截图、文档、广告、拼图提示词；只有非照片
   相似度领先至少 `PHOTOWALL_CLIP_NON_PHOTO_MARGIN`（默认 0.03）才拒绝。提示词
   向量会在进程内缓存，Immich ML 暂时离线不会阻断导入。
3. `backend/curation.py` 生成与模板无关的 `event_id`、`memory_score` 和 `memory_reasons`。
4. `backend/dedup.py` 综合 dHash、内容签名和 CLIP 距离做相似去重。
5. `backend/selection_policy.py` 根据模板 ID 解析策略。
6. `backend/selector.py` 使用策略权重排序，并以 CLIP 与事件约束降低同质化。
7. 模板引擎只接收最终照片路径并排版。

## 当前默认规则

默认最终分：

```text
0.25 × 画质 + 0.20 × 美观 + 0.35 × 用户偏好 + 0.20 × 回忆价值
```

回忆价值是可解释的启发式分数。目前会考虑人物、宠物、地点/旅行、相册内少见内容、完整事件以及半年以上未回顾内容。明确非照片的回忆分始终为 0，回忆价值不能让截图、文档或拼图重新进入候选池。别人分享但缺少 EXIF 的真实照片可以正常参与。

事件按拍摄时间做中立聚合：相邻照片间隔不超过 4 小时归入同一事件。事件不绑定模板，后续可继续加入 GPS 距离、人物重合度和 CLIP 场景变化作为分割条件。

## 配置入口

所有权重和绑定关系位于 `config/selection_profiles.json`。后端每次解析策略时读取该文件，因此调整后不需要重新分析图片。

### 调整默认权重

修改 `profiles.default.weights`。四项权重不必手工加总为 1，加载时会自动归一化。

- `quality`：提高会更偏向清晰、曝光正常的照片。
- `aesthetic`：提高会更偏向色彩和构图。
- `preference`：提高会更依赖用户长期点赞/差评训练结果。
- `memory`：提高会更偏向人物、宠物、事件和久未回顾照片。
- `semantic_diversity`：越高，最终画面越不容易出现视觉相似照片。
- `event_diversity`：越高，越倾向从不同事件各选照片。

建议每次只调整一个参数，幅度控制在 0.05～0.10，并固定同一批测试照片做 A/B 对比。不要同时修改评分权重、CLIP 去重阈值和模板，否则无法判断变化来源。

## 后期绑定主题模板

当前 `template_bindings` 为空，所以全部模板使用 `default`。需要绑定时只修改配置：

```json
{
  "template_bindings": {
    "travel_grid": "travel",
    "pet_collage": "pet",
    "family_album": "family"
  }
}
```

绑定之后，照片的 CLIP、人脸、事件和回忆特征不会重新计算；只有排序与多样性规则发生变化。若多个视觉模板共用同一主题，可以全部映射到同一个 profile。

新增主题时，先在 `profiles` 中复制一个接近的配置并改名，再添加模板映射。不要在模板 JSON 或 `selector.py` 中增加主题条件分支。

## 哪些调整需要重新分析照片

不需要重新分析：评分权重、主题绑定、多样性强度、模板样式。

需要重新分析：更换 CLIP 模型、改变人脸模型、改变相机来源审核、增加新的客观照片特征。修改事件分割规则后只需重跑策展前处理，不需要重新生成 CLIP 向量。

## 人物确认的后续规则

人脸模型只能提出候选，不能直接把身份当成已确认事实。未来增加人物主题前，应提供：

- 人物命名、合并、拆分和移出错误照片；
- `model_inferred` 与 `user_confirmed` 两种来源；
- 用户确认结果优先，重新聚类不得覆盖；
- “不展示某人”作为最高优先级隐私规则，在主题筛选前执行。
