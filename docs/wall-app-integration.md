# 整墙交互合入 App 与预览

整墙交互已增量整合到现有 React Native App，并于 2026-09-11 随 `1.3.4（24）` 发布到 TestFlight。下文保留首次本地预览的实现与验证记录，发布状态见末节。

- 导航扩展为当前展示／偏好／我的。当前展示使用独立 `WallExperience` 组件。
- 首次授权、设备连接、偏好、更新设置保留；完成设置后进入整墙预览。网页重新体验首次设置时重新进入待确认状态，已有正向事件保留。
- 网页预览从本地实验台获取真实精选照片组成的整墙图；确认前没有模拟当前墙。换组不产生负向偏好，多留一会儿记录整墙与模板证据，重复点击不重复加权。
- 人物偏好调整为正向的“想多看到谁”，新操作只产生 normal/more。历史 hide 项保留在快照和过滤逻辑里，不自动解除，在新正向候选列表中略去。
- 原有设备管理、共同使用、更新时间、偏好版本、展示记录仍保留。

## 预览与验证

入口 `http://127.0.0.1:8771/preview` 为手机尺寸外框，内部实际加载 Expo 导出的 App；`/?preview=wall` 是仅 Web 生效的快捷预览入口，不写真实设备授权或连接状态。

本机预览工具 `tools/preview_wall_app.py` 仅监听本机，代理现有本地 `/api/wall-demo` 和整墙图片，无任意代理目标。该工具及其本地实验数据不属于本次 App 源码推送范围，单独检出 App 分支不会提供这套预览服务。图片不打入 App 原生包。浏览器状态按演示设备和精选范围隔离，不调用设备发布接口。

Web 与 iOS Hermes 导出通过（最终结果在 `outputs/wall-app-integration/validated/`）；4 项 App 整墙状态测试、3 项偏好兼容回归通过。浏览器验证首次确认、停留、换组、导航、模拟授权与配网、偏好到更新设置到当前展示衔接，并核对手机尺寸布局。

首次预览的原始 App 文件备份、增量补丁与源码指纹存于本机 `outputs/wall-app-integration/`；签名 IPA 的归档位置见末节。`outputs/` 不上传到 GitHub。

仓库内可复现的 App 回归检查：

```sh
node --test tests/test_native_wall_receipts.cjs tests/test_wall_app_state.cjs tests/test_preference_integration.cjs
```

## 尚未接入的设备能力

原生端复用既有画面生成和发布方法，当前画面仅在设备 revision 与 displayed_revision 匹配时标为设备已确认。停留调度接口尚未实现，原生端该按钮不可用并明确提示；网页仅演示一天停留，不影响真实更新计划。

此轮不宣称将本地冻结精选引擎迁入线上 `generateWall`，也没有自动学习模板权重或云端保存停留事件。真实设备离线／待上屏状态、不可变预览图和模板正向反馈消费仍需服务端联调。已有生成路径仍沿用原服务能力；Web 中的真实本地照片墙只是预览数据适配。
