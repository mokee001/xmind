# GPIO40 开机广播与自动回连

版本：`0.3.9-transfer.gpio40.3`。在 `9762bd9`（`0.3.9-transfer.gpio40.2` 开机广播/回连）上增加交互提示音；GPIO40 基础：`d47b06563b08fcdd515734c315ef24de8c6eaff9`（`0.3.9-transfer.gpio40.1`）。

## 最终按键规则

| 状态/操作 | 行为 |
| --- | --- |
| 冷上电或待机后开机 | 自动广播 PhotoWall BLE 服务，随后连接已保存的 Wi-Fi；无需短按 |
| 正常短按 GPIO40 | 播放一次短提示音；不重启、不进入配网、不清除 Wi-Fi 或绑定 |
| App 提示连接确认时短按 GPIO40 | 确认当前 BLE 连接；物理按下必须晚于该连接建立，松手后 30 秒内有效 |
| 开机状态长按 3 秒 | 请求关机待机；下载、上传或屏幕刷新结束后关闭网络、音频与面板 |
| 待机状态长按 2 秒 | 开机并自动广播；短碰不启动，同次长按不重复触发关机 |
| 蓝牙断开 | 500 ms 后恢复广播，不改变 Wi-Fi 或云端绑定 |

GPIO40 仍使用轻睡待机，保留原供电、音频和面板驱动；不是切断电池电源。BOOT 上电长按恢复出厂的维护入口保持原行为，不用于本次验收。

## 提示音

| 事件 | 声音 | 触发条件 |
| --- | --- | --- |
| 开机状态短按 GPIO40 | 一声短音，65 ms | 松手并通过消抖后一次；提示按键已收到，不代表云端绑定完成 |
| 主动配网成功 | 两声上行短音，280 ms | App 通过 BLE 提交 Wi-Fi 后，设备实际取得 Wi-Fi 连接；旧热点配网入口在重启后实际连上时播放一次 |
| 绑定成功 | 原三声上行成功音，420 ms | 云端已明确返回未绑定，随后确认已绑定；待确认状态跨重启保留，成功后清除 |
| 长按开机 / 关机 | 原开机 / 关机音 | 保持原时序、音量和板载 ES8311 引脚 |

Wi-Fi 成功音只表示连上路由器；云端暂不可达不会播放绑定成功音。已经绑定的设备启动、更换 Wi-Fi 后恢复既有绑定、普通蓝牙回连和自动 Wi-Fi 重连均不重复播放绑定成功音。只有设备从云端确认了新的绑定状态，才会播放三声成功音；云端轮询与网络延迟可能使提示晚于 App。

提示音均在主任务运行，不在 GPIO 采样任务或 BLE 回调内播放。下载/刷新等忙碌阶段的短按延后到安全空闲点处理；按键抖动、长按松手、待机短碰不产生短按音。关机请求优先于配网/绑定成功音。音频驱动失败不阻止确认和联网，串口保留错误记录。

## App 配合

配套 App 记住经确认的外围设备 UUID，仅为当前有效云端绑定建立后台可恢复的 BLE 连接；读取加密特征核对完整硬件 ID。云端绑定和设备名称不作为本机已配对的证据。旧版 App 未持久化外围设备 UUID，升级后需在这部手机补一次连接确认；之后每次开机和断线均可回连。

普通回连不发送 `authorize`、`scan`、`provision` 或 `cancel` 命令。新手机/主动修改 Wi-Fi 使用原配对流程，并保留短按物理确认与 setup token 校验。iOS 系统配对弹窗仍由系统控制。

BLE 信息增加 `supportsLinkReconnect: true` 和 `physicalConfirmationMode: "shortPress"`。旧 App 可继续手动配网；自动回连及短按提示需要配套 App。

App 切换账号、解绑、离开页面和进入主动配网时先取消并排空旧的连接任务，避免同一蓝牙管理器抢占连接。iOS 增加 bluetooth-central 后台模式与状态恢复；手机蓝牙关闭、设备不在范围内或用户强制退出 App 时不能承诺立即回连。

## 验证

- ASan/UBSan 原生回归覆盖 680 组按键边界、I2S 音频、帧传输、开机广播、短按不重启、关机延后、30 秒物理确认、断线确认失效及取消配网不切断现有 Wi-Fi。
- 提示音回归执行生产函数，覆盖短按一次/消抖/长按抑制/刷新延后、BLE 和热点配网成功、错误密码/无网络/超时/取消静音、重试和重连不重复播放、云端绑定状态跨重启与关机优先。五种声音均验证 PCM 时长、PA 静音及 I2C/I2S 故障清理。
- App 回归覆盖缓存 UUID 回连、完整身份核对、新手机不静默配对、iOS 状态恢复、取消等待中的原生连接、扫描撤销、账号切换、掉线重试及关蓝牙状态；同时回归已有配网和绑定逻辑。
- 实板新手机配对、旧手机开关机回连、提示音、长按开关机和真实投屏仍需安装后的现场验证。

## 刷写限制

先核对设备、分区表和活动槽，保存该设备自己的当前应用备份；仅更新应用槽，不擦除 NVS、OTA 数据、Wi-Fi 或绑定。回滚使用该设备原应用。旧版交接记录中的验收结论不代表本版已经通过实板验收。
