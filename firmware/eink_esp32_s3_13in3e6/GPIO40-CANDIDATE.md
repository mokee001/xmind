## 基线与回滚

- 原固件读回的应用为 1,706,672 字节，SHA-256 `eee792d2184195bb2f50bc0eb6775eda1953c58f9a979c1c1883c13af4f2dfe6`。私有原应用和 32 MiB 整片备份已复核，均未放入交付目录。未做实机恢复演练。
- 未修改源码重建时将 SDK 的 `__FILE__` 前缀映射回 `/tmp/echo-platformio`。六段的地址、长度一致；逐字节比较仅有 ELF 标识和编译日期/时间不同。该比较针对加载段，不表示整个 BIN 哈希相同。
- 原件、对照版与候选使用同一分区表。业务板备份时 `app0` 为 `0x10000`、容量 `0x640000`，**不是给任意板固定写这个地址的依据**。每次操作前重查 MAC、活动槽及分区，限定应用分区，保留 bootloader、分区表、NVS、OTA 数据和其他槽。
- 默认回滚只恢复同一块板自己的原应用；整片恢复需要单独确认，会覆盖后来本地状态。刷回固件不会撤销云端解绑、所有权转移或 token 撤销。备用板使用自己的备份，不克隆业务板的 NVS。

## 硬件和操作

- 仅适用已核对的 Waveshare ESP32-S3-ePaper-13.3E6：无源外键 `OUT → GPIO40`、`GND → G`、不接 `VCC`；喇叭接板载 `SPK`。黑板 `Power Path Out → V/VSYS`、地线共地，蓝板 `BAT` 留空。仅供电不需要固件驱动；不从蓝板电池 ADC 推断黑板电量或充电情况。
- 冷上电按原程序自动启动。在线短按外键，仅本次启动进入配网，不清除原 Wi-Fi 或绑定。App 出现物理确认提示后**再短按一次**，或按原方式按住 BOOT。原 App 文案可能仍只写 BOOT。确认窗口限当前 BLE 连接、从真实松手起 30 秒、仅使用一次；进入配网不等于授权或认领。
- 开机状态外键长按 3 秒请求待机。进行中的下载、上传和刷新先完成，才关闭网络、音频与面板；关机时松手，待机后重新长按 2 秒开机。短碰不应开机，同一长按不能再次关机。GPIO40 是数字 GPIO，使用轻睡唤醒；初始化或入睡失败会退回轮询，不承诺待机电流。
- 板载 ES8311 与功放沿用旧板配置。开机、关机有提示音；成功音仅用于凭据提交后观察到云端 `claimed:false → true`，不因 BLE 连接、返回 token 或已绑定设备换网而播放。若未观察到该变化，不以提示音判断绑定失败。
- 原 BOOT 上电恢复出厂仍会清除凭据；**不要在业务板用这个操作验收按钮**。

## 已验证与待验证

本机通过 ASan/UBSan：680 个按键矩阵场景、板载音频驱动、原版断流/超时/边界帧测试；直接执行 17 个主流程/待机生产函数和 7 个 BLE 生产函数，覆盖断线、过期、换网、关机延后、短碰、轻睡失败等。另逐字核对 15 个关键原函数和 BLE 标识、权限、本地 HTTP 路由。原分支的设备生命周期测试仅在环回地址、临时数据和合成账号上运行，校验了 960,045 字节帧、认领、保留绑定换网和解绑后再次认领。

备用板仅验证了原版烧录和启动，未完成 App 对照。候选在另一块业务测试板上仅写活动 `app0`；复位前独立校验并完整读回 1,788,992 字节，与候选镜像逐字节一致。引导区、分区表、NVS 和 OTA 数据在烧录窗口内未变。烧录时只接蓝板数据 USB，断开电池及黑板到蓝板的供电线。

- 手动按 RST 后串口报告候选版本，现场听到开机音。
- GPIO40 短按记录到按下和松开，时长 765 ms，只计一次。按下前蓝牙配网已就绪，这次不能证明短按进入配网或 App 授权成功。
- GPIO40 长按在约 3 秒时触发待机请求，松手时记录 3600 ms。现场听到关机音；随后固件报告已配置轻睡待机，未测电流。

实机待验：待机短碰不启动、只用外键长按唤醒、在线短按进入配网、原 App 的物理确认与认领成功音、换网保绑定、传图及屏上出图、刷新中长按、整机电池供电和充电。认领或解绑仅用测试资产。
