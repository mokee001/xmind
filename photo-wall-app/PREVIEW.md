# Expo 产品管理预览

## 启动

在 `photo-wall-app` 目录执行：

    npm run web

浏览器访问终端显示的地址（本地验证使用 `http://127.0.0.1:8081`）。

## 可操作流程

- 首页：查看设备状态、当前画面和待处理人物提醒；“创建新画面”仅保留简洁入口，不在首页堆叠编辑模块。
- 相册：选择/取消同步相册，查看授权和同步状态。
- 设置：查看家庭角色、邀请成员、管理设备和自动化开关；从“人物与展示权限”进入人物管理，把人物设为允许展示、每次审核或不展示。
- 页面在桌面浏览器和 390px 手机视口下都有独立导航布局。

## 安全说明

这是产品交互预览，使用本地演示状态和现有后端照片缩略图：

- 打开预览不会请求系统相册权限。
- 打开预览不会上传照片。
- “确认并发布”只演示发布状态，不会调用真实墨水屏推送接口。
- 后续接入 `/api/v1/*` 账号、家庭、设备、人物策略和草稿接口后，再启用真实发布。
